## 4. Статусы и приоритет

- **Сохранены:** `DEC-05=FIXED`, `MAIL_DELIVERY_VERIFICATION=VERIFY`, `DEC-06=BLOCKED`, `DEC-10=PROPOSED`, `DEC-11=BLOCKED` для PROD, `DEC-12=VERIFY`; прочие статусы и маппинг DEC→ADR — точно по архитектуре v1.3 §12.1.
- **Новый инженерный процесс:** `main/develop` — целевая политика разработки, не активация инфраструктуры. DEMO — планируемая среда; STAGING остаётся `PROPOSED`. W0-01 сохраняет только локальный `main`, CI включается W0-11.
- **Иерархия:** бизнес-нормы v9.8 (`Use_Cases`, `ER`, `Стек`, `Функциональная_декомпозиция`) старше инженерного регламента. При конфликте агент предъявляет расхождение и не меняет существенные требования сам.
- **Секреты/география:** реальные пользовательские данные и backup не попадают в CI, DEMO или зарубежные GitHub-hosted runners; отдельные data-flows и проверка РФ-хранения до PROD.
