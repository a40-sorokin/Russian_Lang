## 1. Источник и его целостность

Базовый архив r1 прочитан **из вложения заказчика в этой беседе**, не из предыдущей библиотеки. ZIP успешно прошёл CRC-проверку. Внутренний `MANIFEST_v9.8-DEC05-r1.json` перечисляет 14 файлов, и **все 14** совпали с указанными размерами `bytes` и SHA-256. В исходный ZIP ничего не записывалось.

`MANIFEST_v9.8-DEC05-r6.json` описывает файлы **настоящего полного ZIP**: каждому файлу кроме самого манифеста соответствуют `filename`, `bytes`, `sha256`. Отсутствуют необъявленные файлы; манифест не включает себя во избежание циклического хеша. Старый манифест r1 сохранён как факт происхождения через его SHA-256 и реквизиты в новом манифесте, но **не лежит вторым активным `MANIFEST*.json` в корне**.

## 3. Правила дальнейшего внедрения

1. **W0-01:** только локальный Git, `main`, каркас Next.js, нормативные документы и отчёт. W0-01 v1.2 не требует `develop`, GitHub remote, CI и доступа к VPS.
2. **W0-11:** отдельным заданием GitHub remote, ветка `develop`, PR/branch rules и реальный CI. До фактических успешных прогонов — не `W0-11_READY`.
3. **Релизы, DEMO, PROD:** отдельные решения владельца о registry/VPS/доменах/секретах, тесты совместимости миграций, данные и логирование в РФ. DEMO не использует PROD-данные.
4. `DEC-05=FIXED` (Postfix outbound РФ, Mailpit local), `MAIL_DELIVERY_VERIFICATION=VERIFY`; `DEC-06=BLOCKED`, `DEC-10=PROPOSED`, `DEC-11=BLOCKED` для production, `DEC-12=VERIFY`. Остальные DEC и соответствие ADR остаются согласно §12.1 архитектуры v1.3.
5. Даже полный, корректно подписанный манифестом архив — это **документация, не доказательство работоспособной системы**. Ни GitHub workflows, ни серверы, ни реальная SMTP-доставка при подготовке релиза не выполнялись/не проверялись.

## 4. Проверка архива

Проверяющая программа или AI-агент должны открыть **в данном ZIP** `MANIFEST_v9.8-DEC05-r6.json`, сравнить **точный** набор имён и для каждого `files[]` проверить `bytes` и SHA-256. Манифест в состав собственных файлов не входит. Документы надо копировать в репозиторий побайтово, не запускать форматирование Markdown поверх согласованных текстов. При несовпадении любой записи отметить `BLOCKED: SOURCE_DOCUMENTS_INCOMPLETE` и остановить зависимую приёмку W0-01.
