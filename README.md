Russian Lang
Активности для подготовки к ЕГЭ по русскому языку.

Веб-сервис со следующими основными возможностями.

Первая очередь реализации:
1. Дерево правил русского языка. Пользователь имеет возможность наглядно отслеживать прогресс по каждому узлу.
2. Пользователь выполняет онлайн-диктанты. Диктант - текст с пропущенными буквами и знаками препинания, пользователь должен заполнить пропущенные места. Каждое пропущенное место связано с одним из правил из дерева правил. Таким образом, отслеживается прогресс в освоении правил (задания в пройденных диктантах выполнены хорошо или с ошибками, или правила еще не отрабатывались пользователем).

Вторая очередь реализации:
3. Пользователям предлагается выполнить челенджи - регулярные задания. Задания в челенджах так же связаны с правилами в дереве правил, что помогает отследить прогресс пользователя в дереве правил.
4. Пользователь может делиться своим прогрессом с помощью "тайных сслылок".

Третья очередь реализации:
5. Референсная модель: предлагаем пользователям привлекать других пользователей за процент от их подписок.
6. Интеграция с профессиональными репетиторами. Предлагаем репетитору использовать онлайн диктанты для своих учеников. Можно создавать свои уникальные онлайн-диктанты, можно проводить на платформе свои уникальные челенджи. Прогресс учеников также отслеживается в дереве правил.
